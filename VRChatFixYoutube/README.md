# VRChat YouTube 再生修正ツール

VRChat で YouTube が再生できないプレイヤー向けの簡易的なツールです。  
再び再生できなくなった場合は、同じ手順で再度実行してください。

## 概要

VRChat は内部で `yt-dlp` を利用し匿名アクセスで動画を取得しています。  
使用している回線が MAP-E や v6 プラス などの `IPv4 over IPv6` 技術を用いている場合、通信が IPv6 経由となり、YouTube 側でボット判定されアクセスが制限されることがあります。  
本ツールは hosts ファイルを用いて YouTube へのアクセスを強制的に IPv4 に寄せ、再生できる状態を取り戻します。

## 注意事項

- Windows 専用です。
- 恒久的な解決策ではありません。状況が再発したら再度実行してください。
- hosts を書き換えるため管理者権限が必要です。
- 変更中は他ソフトの YouTube アクセスも IPv4 固定の影響を受ける可能性があります。
- 自己責任でご利用ください。企業ネットワーク環境では使用しないでください。

## 使い方

1. [`VRChatFixYoutube.bat`](https://raw.githubusercontent.com/ballban/Windows_Scripts/refs/heads/main/VRChatFixYoutube/VRChatFixYoutube.bat) をダウンロードします。（右クリック保存）
2. ファイルを右クリックし「管理者として実行」を選びます。
3. 指示に従い処理が完了するまで待ちます。
4. VRChat を再起動し YouTube 動画が再生できるか確認します。

## 解決方針

大きく以下の 2 つが考えられます。

1. IPv6 を使わず IPv4 経由にする
2. 匿名アクセスをやめ、認証付きアクセスにする

これを実現する具体的な手段は複数存在します。

## 方法 1-1

`hosts` ファイルで YouTube への接続先を取得した IPv4 アドレスに固定します。`ping youtube.com -4` などで得た IPv4 を `hosts` に追記し、名前解決を強制します。

懸念点:

- YouTube の IP が変わると再生不可になる可能性がある
- 他のブラウザ/アプリの YouTube 接続も同じ IP に固定される

自分は実運用で数か月問題なく使えている。

## 方法 1-2

ネットワーク設定で IPv6 を完全に無効化する方法。  
追加ツールが不要で最も簡単ですが、高速化目的で導入した IPv4 over IPv6 の利点を失う本末転倒なため、ここでは推奨しません。

## 方法 2

`yt-dlp` に自身の YouTube アカウント認証情報を設定してアクセス制限を回避する方法。理論上は可能だが、VRChat で使用されている `yt-dlp` は改造版で、外部入力ができない可能性がある。  
通常版に差し替える手法もネットにあったが、ゲーム終了時に再度改造版へ上書きされるため、スクリプトで毎回上書きする必要があり結構面倒くし、`yt-dlp`のバージョン管理もしないといけないため割と面倒。
